# FruitSlash-exe
🍎 FruitSlash An addictive, fast-paced slicing game!  Features:  Web: Play directly in your browser. Desktop: Includes FruitSlash.exe for Windows. Built with: HTML5, CSS3, and Vanilla JavaScript. Quick Start:  Open index.html in any browser. Run FruitSlash.exe from the /dist folder for the desktop version. Enjoy slicing!
